# 生成校园数据总览报表

一条命令生成 8 个 Sheet 的模板报表；只读现有 8 张业务表，不新增数据库表。

## 执行

在仓库根目录运行：

```powershell
python scripts/generate_campus_report.py --json
```

把返回的 `download_url` 交给用户下载；`file_path` 是报表的本地绝对路径。

## 可选参数

| 参数 | 说明 |
|---|---|
| `--target 八年级` 或 `--target 八年级一班` | 限定年级/班级，省略为全校 |
| `--start-date` / `--end-date` | 出勤、请假统计区间，格式 `YYYY-MM-DD`，省略为最近 30 天 |
| `--output-dir` | 输出目录，默认 `data/reports`；自定义目录不在下载接口内 |
| `--push` / `--chat-id` | 推送到飞书群；仅在用户明确要求时使用 |
| `--json` | 机器可读输出，便于解析报表编号与各 Sheet 行数 |

## 约束

- 只读 8 张业务表，不得新增表，也不得把报表数据写入数据库。
- `--push` 是外部可见操作，只有用户明确说“推送到飞书”时才执行。
- 输出中不得出现 `.env` 里的 Key、secret、token；脚本本身不打印这些内容。
- 失败时把返回的 `error` 原文告诉用户；常见原因是库中没有该年级/班级。

## Sheet 内容

年级概况、教师名录、班级概况、学生花名册、家长联系表、出勤汇总、请假记录、课程表。
